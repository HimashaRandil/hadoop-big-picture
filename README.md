# Hadoop — the big picture

An interactive, narrated map of a Hadoop cluster for 6DATA006W Big Data Analytics (Week 4: Introduction to Data Processing with Hadoop).

It shows which programs (NameNode, DataNode, ResourceManager, NodeManager, HiveServer2, HBase, Kafka, ZooKeeper, Sqoop, Flume, Oozie, Spark) run on which machines, and animates how they work together — on an on-premises cluster and on Azure HDInsight.

- **Watch the story** — 17 narrated scenes, like a video. Tick *Lecture mode* to pause after each sentence.
- **Explore freely** — click any machine, program, container or block for a deep dive.
- Keyboard: Space = play/pause, → = next sentence/scene, N / P = next / previous scene.

Single self-contained `index.html`, no build step.
